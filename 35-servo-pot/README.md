# Модуль 3.5 / урок 35 — Керування сервоприводом за допомогою PWM

## Завдання

Потенціометр керує положенням вала сервопривода в пропорції 1:1. Розбіжність
діапазонів обрізається — працює тільки та частина, що збігається. Кут
відхилення від крайнього лівого положення логується в консолі.

## Схема

```
3V3 ──[ потенціометр 10к ]── GND
            │
            └── GPIO9 (ADC1_CH8)

GPIO14 ── сигнал серво (помаранчевий)
5V     ── живлення серво (червоний)
GND    ── спільна земля (коричневий)
```

Серво живити **від зовнішніх 5 В**, не від піна плати. У момент старту воно
тягне струм, який просадить живлення, і контролер піде в ребут. Земля при
цьому має бути спільна, інакше сигнал нема відносно чого міряти.

## Що тут означає «1:1»

Потенціометр крутиться приблизно на 270°, серво ходить на 180°. Це різні
діапазони, тому «1:1» не може означати «весь хід ручки на весь хід вала» —
це була б пропорція 1.5:1.

1:1 — це один градус ручки на один градус вала:

```
pot_deg   = raw × 270 / 4095      ← де стоїть ручка
servo_deg = clamp(pot_deg, 0, 180) ← той самий градус, але обрізаний
```

Спільний діапазон — це менший з двох, тобто 180°. Перші 180° ручки працюють
один-в-один, а останні 90° — мертва зона: вал уже стоїть у крайньому правому
положенні. У логах така ситуація підписана `(поза діапазоном)`.

`USABLE_RANGE_DEG` рахується з обох констант, тому якщо поставиш серво на 270°
або інший потенціометр — міняєш одне число, решта підлаштується.

## Кут від крайнього лівого

`servo_write_deg()` приймає градуси від 0, де 0 — крайнє ліве положення
(імпульс 500 мкс), 180 — крайнє праве (2500 мкс). Саме це значення і йде в лог,
тобто логується відхилення від лівого краю, як вимагає умова.

Перетворення кута в duty:

```c
pulse_us = 500 + (2500 - 500) × deg / 180
duty     = pulse_us × SERVO_MAX_DUTY / 20000
```

Множення перед діленням — інакше цілочисельна арифметика з'їдає точність.

## Згладжування

Перед перетворенням значення ADC проходить через ковзну середню на 8 вимірів.
Без неї шум молодших бітів дає дрібне тремтіння вала навіть на нерухомій ручці:
серво відпрацьовує кожен випадковий одиничний крок і гуде.
