# Урок 29 / Модуль 2.8 — STM32 знайомство

## Завдання

> Використовуючи код з уроку додати обробку стану кнопки. Світлодіод на платі
> повинен реагувати на натискання кнопки. Реакція світлодіода довільна.
> Використати STM32 HAL.

## Плата

WeAct Black Pill, STM32F411CEU6.

| Що    | Пін  | Схема                                 | Активний стан |
|-------|------|---------------------------------------|---------------|
| LED   | PC13 | анод на 3V3, катод через резистор на пін | нуль (sink) |
| KEY   | PA0  | кнопка замикає пін на GND              | нуль, треба pull-up |

Тому `GPIO_PIN_RESET` на PC13 — світлодіод **світить**, а натиснута кнопка читається як `GPIO_PIN_RESET`.

## Рішення

Поки кнопка натиснута — світлодіод блимає з періодом 0.5 с (той самий
`HAL_GPIO_TogglePin` + `HAL_Delay(500)` з уроку). Коли відпущена — гасне.

```c
if (HAL_GPIO_ReadPin(KEY_GPIO_Port, KEY_Pin) == GPIO_PIN_RESET)
{
  HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
  HAL_Delay(500);
}
else
{
  HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, LED_OFF);
}
```

Дебаунс не потрібен: читається не фронт, а поточний стан кнопки, тож брязкіт
контактів ні на що не впливає.

Тактування — від внутрішнього HSI 16 МГц без PLL: для блимання швидкість не
потрібна, а HSI не залежить від того, який кварц стоїть на платі.

## Як зібрати

1. STM32CubeIDE → File → New → STM32 Project → MCU `STM32F411CEUx`.
2. У `.ioc`: `PC13` → `GPIO_Output`, `PA0` → `GPIO_Input`, Pull-up.
   RCC можна не трогати (за замовчуванням HSI).
3. Згенерувати код, замінити `Core/Src/main.c` файлом з цієї папки.
4. Build → Run (ST-Link / DFU).

Перевірка: натиснути KEY — світлодіод блимає, відпустити — гасне.
