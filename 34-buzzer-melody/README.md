# Модуль 3.4 / урок 34 — Програвання звуку на зумері (PWM)

Обране **Завдання 2**: синтезатор на кілька нот, що грає просту мелодію.

## Схема

```
GPIO16 ──[ пасивний зумер ]── GND
```

Зумер має бути **пасивний**. Активний має свій генератор усередині й гудить
на одній частоті незалежно від того, що ти йому подаєш — мелодії з нього не
вийде.

## Як це працює

Нота — це частота. У LEDC частоту задає таймер, тому зміна ноти — це
`ledc_set_freq()` на тому ж каналі.

Duty тримаємо рівно половину шкали: виходить меандр, рівно півперіоду високий
рівень, півперіоду низький. Для зумера duty відповідає не висоті, а приблизно
гучності/тембру, і 50% дає найгучніший чистий тон.

Мелодія — `C C G G A A G`, початок Twinkle Twinkle Little Star.

Між нотами стоїть пауза 60 мс (`GAP_MS`). Без неї дві однакові ноти підряд
(`C C`) злилися б в одну довгу — частота ж не міняється, і на слух це один звук.

Частоти взяті з четвертої октави: C=262, D=294, E=330, F=349, G=392, A=440 Гц.
