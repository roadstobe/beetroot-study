# Модуль 3.2 / урок 32 — Калібрування даних з ADC

## Завдання

Потенціометр подільником на ADC, зчитування кожні ~100 мс. Для кожного виміру:
сире значення, напруга за формулою, напруга через калібрований ADC, похибка у
відсотках. Вивести таблицею в консоль.

## Схема

```
3V3 ──[ потенціометр 10к ]── GND
            │ (середній вивід)
            └── GPIO9 (ADC1_CH8)
```

## Параметри, які впливають на результат

| Параметр | Значення | Що означає |
|----------|----------|------------|
| Опорна напруга | 3100 мВ | повна шкала при цій атенюації |
| Атенюація | 12 dB | розтягує діапазон приблизно до 0…3.1 В |
| Розрядність | 12 біт | коди 0…4095 |

## Дві напруги і чому вони різні

**За формулою** — проста лінійна пропорція:

```
U = RAW × 3100 / 4095
```

Вона припускає, що ADC ідеально лінійний і повна шкала рівно 3.1 В.

**Калібрована** — `adc_cali_raw_to_voltage()` зі схемою curve fitting. Вона
бере коефіцієнти, записані у eFuse конкретного чипа на заводі, і враховує
реальну нелінійність саме цього екземпляра.

Похибка між ними — це і є те, що дає калібрування. Вона не стала: більша на
краях діапазону (біля 0 і біля 4095) і менша в середині. Там, де вона стрибає,
і є ділянки нелінійності.

## Збірка

```
idf.py set-target esp32s3
idf.py build flash monitor
```

Крути потенціометр — рядки таблиці підуть по всьому діапазону.
