# Модуль 3.1 / урок 31 — Проста ковзна середня (SMA)

## Завдання

LDR у подільнику напруги на ADC1, зчитування в режимі oneshot, фільтрація
через Simple Moving Average. Темніє — світлодіод вмикається, світлішає —
вимикається. Мерехтіти при дрібних коливаннях не повинен — два пороги
(гістерезис).

## Схема

```
3V3 ──[ LDR ]──┬── GPIO9 (ADC1_CH8)
               │
              [10k]
               │
              GND
```

Більше світла → опір LDR падає → напруга на вході росте.
Тобто **темрява = мале значення ADC**.

Світлодіод: `GPIO17 ──[220Ω]──|>|── GND`.

## Чому гістерезис, а не один поріг

З одним порогом значення, що коливається біля нього, перемикало б світлодіод
туди-сюди на кожному вимірюванні. Тут порогів два: вмикаємо нижче `DARK_LEVEL`
(1200), вимикаємо вище `LIGHT_LEVEL` (1800). Між ними стан не міняється взагалі.

SMA прибирає швидкий шум, гістерезис — повільне «гуляння» біля межі. Треба обидва.

## Як SMA зроблена

Кільцевий буфер на 16 значень плюс поточна сума. На кожному кроці з суми
віднімається те, що випадає з вікна, і додається нове — це O(1), а не
перерахунок усього вікна.

Вікно 16 × 50 мс = 0.8 с інерції. Більше вікно — спокійніше, але повільніше реагує.

## Збірка

```
idf.py set-target esp32s3
idf.py build flash monitor
```

Пороги підбираються під конкретний LDR і освітлення — дивись `raw` у моніторі.
